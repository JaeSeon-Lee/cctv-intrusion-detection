## 1. 목표

실제 CCTV 관제 환경을 최대한 비슷하게 구현하는 것.

- 여러 화면을 동시에 보며 위험구역을 감시
- 사람이 구역에 일정 시간 머물면 경보
- 상시 녹화 + 침입 구간 클립·로그 자동 저장
- 다시보기로 사건 확인

## 3. YOLO 4화면과 큐

### 상황

- CCTV처럼 **영상(캠) 4개**를 동시에 재생·감시
- 사람 위치는 **YOLO**로 잡음 (박스 = 탐지 결과. 이 프로젝트는 ID 트래킹이 아니라 프레임별 탐지)
- 화면 재생은 매 프레임 돌아가지만, YOLO 추론은 프레임마다 시간이 걸림

### 사양 이슈

- YOLO 워커를 **1개**로 돌리면, 4캠에서 쏟아지는 프레임을 전부 처리할 수 없음
- 예전에는 대기 프레임이 **공용 1칸**이라, 어느 한 캠만 계속 처리되고 다른 캠 박스가 멈추는 것처럼 보임
- 모델 4개를 올리면 메모리·GPU 부담이 커짐 (특히 노트북/MPS)

### 선택한 방법: 캠별 최신 프레임 큐

- YOLO는 **1개** 유지
- 캠마다 **가장 최근 프레임 1장만** 보관
- 한가해지면 캠1 → 캠2 → … 돌아가며 추론
- 처리 못한 중간 프레임은 버리고, 박스는 직전 결과를 유지

즉, “모든 프레임을 YOLO로 다 돌린다”가 아니라  
**실시간 CCTV처럼 화면은 끊기지 않게 두고, 탐지는 사양이 되는 속도로·캠이 공평하게** 돌리는 구조입니다.
